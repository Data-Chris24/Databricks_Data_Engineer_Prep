Grants for

Each chip shows one privilege on one object for this principal: filled = granted on that object, dashed = inherited from above, plain = not held. Activate a chip to run the GRANT or REVOKE it names.

    -- activate a chip to run a statement

    Who can read what

    SHOW GRANTS ON TABLE

    Inherited grants appear with the object they live on. USE CATALOG and USE SCHEMA never appear here, so this listing cannot show the traversal trap.
